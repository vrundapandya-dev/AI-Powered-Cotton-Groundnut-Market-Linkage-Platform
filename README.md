# 🌾 AI-Powered Cotton & Groundnut Market Linkage Platform

A web-based advisory platform designed to help cotton and groundnut farmers make better market-related decisions using mandi prices, price forecasting, buyer suggestions, storage recommendations, quality grading, and income tracking.

## 🌐 Live Demo

[🚀 View Live Demo]([https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/](https://github.com/vrundapandya-dev/AI-Powered-Cotton-Groundnut-Market-Linkage-Platform))

## 🚜 Features

* 📊 **Mandi Price Dashboard** – View cotton and groundnut market prices.
* 📈 **7-Day Price Forecast** – Provides an estimated price trend using linear regression.
* 🤝 **Find Buyers** – Suggests potential buyers based on available crop and offers.
* 💰 **Sell or Store Advisor** – Provides recommendations on whether to sell, wait, or store the crop.
* 🌾 **Quality Grading** – Provides an estimated crop quality grade from an uploaded image.
* 📋 **Income Dashboard** – Track crop sales, quantities, prices, and total income.
* 🌐 **English & Gujarati** – Supports both English and Gujarati.
* 📱 **Responsive Design** – Works across desktop and mobile screen sizes.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* Agmarknet / data.gov.in API
* Browser Local Storage

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The platform can be used directly from the browser.

## ⚠️ Disclaimer

This project is developed **for advisory and educational purposes only**. The prices, forecasts, buyer information, quality grades, and other results may be illustrative, simulated, cached, or unavailable from official government sources. The information should **not be considered guaranteed, official, or financial advice**. Users should verify important market information with reliable official sources before making decisions.

## 📌 Project Purpose

The purpose of this project is to demonstrate how web technologies and AI-based advisory concepts can be used to support farmers in making informed decisions about crop prices, buyers, storage, quality, and income.
